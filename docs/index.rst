MuJoCo ROS Documentation
========================

MuJoCo ROS wraps the MuJoCo simulator with ROS interfaces for launching, controlling, observing, and extending simulations. The release line uses the hybrid package structure and supports ROS 1 and ROS 2 from one shared MuJoCo core.
Python bindings are available for the core environment and bundled plugin packages.

Start with the installation guide if you want to run the simulator, then use the ROS API and plugin sections as the reference for integrating it into a larger system.
