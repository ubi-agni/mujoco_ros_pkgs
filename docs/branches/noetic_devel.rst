``noetic-devel``
================

``noetic-devel`` is the current ROS 1 reference feature set. The goal is to
retire it as the default branch once ``hybrid-devel`` reaches ROS 1 feature
parity.

Stable Features
---------------

* Interactive MuJoCo GUI based on the MuJoCo simulate application.
* Headless execution and no-render execution.
* Offscreen RGB, depth, and segmentation camera streams.
* Pluginlib-based MuJoCo plugin loading.
* ROS services and step action for simulation control.
* Runtime physics tuning through dynamic reconfigure.
* ROS 1 ``ros_control`` integration.
* Native MuJoCo sensor streams.
* CPU ray-collision laser scans.
* Mocap body control through topic and service interfaces.
